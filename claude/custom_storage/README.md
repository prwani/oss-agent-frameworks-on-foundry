# Claude Agent SDK — Custom storage

Mirrors Claude session transcripts into SQLite through the `SessionStore` protocol.

Support level: **alternative**

## Run locally

```bash
cp .env.example .env   # then fill in the values
pip install -r requirements.txt
python main.py
```

## Configuration

| Variable | Required |
| --- | --- |
| `ANTHROPIC_FOUNDRY_RESOURCE` | yes |
| `CLAUDE_MODEL_DEPLOYMENT_NAME` | yes |
| `SQLITE_STORAGE_PATH` | yes |
| `USE_FOUNDRY_STORAGE` | yes |

Authentication uses `DefaultAzureCredential` against the `https://cognitiveservices.azure.com/.default` scope unless `ANTHROPIC_FOUNDRY_API_KEY` is set.
